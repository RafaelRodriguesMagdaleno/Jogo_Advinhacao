# Jogo_Advinhacao
Jogo de adivinhação, criado com base nos ensinamentos do livro : Introdução a programação em C, de Maúricio Aniche, comprado na casa do Código

Nesse primeiro jogo, aprendemos conceitos como : condicionais, loops, números randomicos, ler do teclado, escrever na tela, armazenar valores e manipula-los, executar operações matematicas, entender diferentes tipos de variaveis, tomar decisões dependendo da entrada do usuário
